# AI Workspace Atlas (Faza 1) — plan implementacije

> **For agentic workers:** Use superpowers:executing-plans, if available, to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Delegate only when the user or applicable instructions explicitly authorize it.

**Goal:** Lokalni Python CLI koji skenira projekte, skillove, pluginove, MCP konfiguracije i dokumente i pravi jedan offline `output/index.html` sa pretragom, filterima i detaljima.

**Architecture:** Paket `atlas` u `src/` (Python stdlib + PyYAML). Skeneri pune zajednički `Collector`; `inventory.build_inventory` spaja lokacije, računa duplikate, sortira i validira. `writeout.publish` objavljuje izlaze preko staginga, backupa, journala i locka. `catalog.render_catalog` ugrađuje inventar, CSS i JS u jedan HTML koji radi preko `file://`.

**Tech Stack:** Python 3.13 (min 3.12), PyYAML, `tomllib`, `unittest`, Playwright za Python (samo u lokalnom `.venv`), čisti JS/CSS bez biblioteka.

**Spec:** `docs/specs/2026-10-13-atlas-design.md`, radna revizija 2026-10-13. Izvršilac čita spec i plan zajedno; trenutni spec ima prednost nad starim commitom.

**Revizija plana:** 2026-10-13, poslije pregleda. Oporavak, lock, parseri i završne provjere su precizirani. Prikazani testovi su predloženi testovi, ne već izvršena verifikacija aplikacije.

- Sav kod i izlazi ostaju u `C:\Users\Example\Projects\Archify`. Skenirani fajlovi se samo čitaju.
- Python `>=3.12`; jedina runtime zavisnost `PyYAML>=6`; `playwright` je opcionalna `dev` zavisnost. Instalacija samo u `Archify\.venv`, browseri u `Archify\.playwright-browsers`.

- Iz MCP izvora izlaze samo: ime, profil, scope, `projectPath`, transport, `executableName`, `envNames`, `sourceFormat`. Nikad `args`, vrijednosti `env`, `url`, `headers`.
- Iz `SKILL.md` se čitaju samo `name` (≤100 znakova) i `description` (≤500 znakova).
- Poruke upozorenja i grešaka sadrže putanju i kod, nikad sadržaj fajla.
- HTML: inventar u `<script type="application/json" id="atlas-data">` uz escape `<`, `>`, `&`; DOM samo preko `textContent`; CSP `default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; img-src data:`.
- Limiti: SKILL.md/manifest 1 MiB; konfiguracioni izvori 32 MiB; dubina skill skeniranja 4; 5.000 stavki.
- Exit kodovi: 0 uspjeh, 1 fatalna greška (stari izlazi ostaju), 2 djelimičan rezultat.
- UI tekst i README na BCS-u; bez em-crtica i hype fraza u UI tekstu.
- Simbolički linkovi na ovom računaru traže privilegiju (WinError 1314); test helper pada nazad na junction.
- Commitovi su samo u vlastitom `Archify` repou, nikad u roditeljskom. Ne dodavati unaprijed zadat identitet/model koautora; koristiti stvarnu atribuciju samo kada je primjenjiva. Prije git komandi provjeriti da `git rev-parse --show-toplevel` odgovara Archify rootu.

"""Putanje aplikacije. Sve je relativno korijenu aplikacije, ne cwd-u."""
from __future__ import annotations

from pathlib import Path

PACKAGE_DIR = Path(__file__).resolve().parent
DEFAULT_APP_ROOT = PACKAGE_DIR.parents[1]
UI_DIR = PACKAGE_DIR / "ui"


class AppPaths:
    def __init__(self, root: Path | None = None) -> None:
        self.root = Path(root) if root is not None else DEFAULT_APP_ROOT
        self.config_dir = self.root / "config"
        self.default_config = self.config_dir / "sources.local.json"
        self.example_config = self.config_dir / "sources.example.json"
        self.data_dir = self.root / "data"
        self.output_dir = self.root / "output"
        self.inventory = self.data_dir / "inventory.json"
        self.report = self.data_dir / "scan-report.md"
        self.catalog = self.output_dir / "index.html"
        self.lock = self.data_dir / ".atlas.lock"
        self.journal = self.data_dir / ".publish-journal.json"

    def resolve_config(self, value: str | None) -> Path:
        if not value:
            return self.default_config
        path = Path(value)
        return path if path.is_absolute() else self.root / path

```python
"""Stabilni identiteti stavki."""
from __future__ import annotations

import hashlib
import json
import os


def norm_path(path: str | os.PathLike[str]) -> str:
    """Realpath, apsolutna, a na Windowsu lowercase i '\\'."""
    raw = os.fspath(path)
    try:
        real = os.path.realpath(raw, strict=False)
    except OSError:
        real = os.path.abspath(raw)
    return os.path.normcase(os.path.normpath(real))


def make_id(kind: str, *parts: str) -> str:
    payload = json.dumps([kind, *parts], ensure_ascii=False, separators=(",", ":"))
    return hashlib.sha256(payload.encode("utf-8")).hexdigest()
```

def make_dir_link(link: Path, target: Path) -> str:
    """Pravi link na folder: symlink ako je dozvoljen, inače junction."""
    link.parent.mkdir(parents=True, exist_ok=True)

class FakeFs:
    """Lažni fajl sistem sa Windows separatorima i linkovima."""

    def __init__(self, dirs, files=(), links=None):
        self.dirs = {d: list(c) for d, c in dirs.items()}
        self.files = set(files)
        self.links = dict(links or {})

    def realpath(self, path):
        parts = path.split("\\")
        current = parts[0]
        for part in parts[1:]:
            current = current + "\\" + part
            hops = 0
            while current in self.links and hops < 40:
                current = self.links[current]
                hops += 1
        return current

    def listdir(self, path):
        return list(self.dirs[self.realpath(path)])

        return self.realpath(path) in self.dirs

    def isfile(self, path):
        return self.realpath(path) in self.files

    def lexists(self, path):
        return path in self.links or self.isdir(path) or self.isfile(path)

    def ops(self):
        return FsOps(listdir=self.listdir, isdir=self.isdir, isfile=self.isfile,

from __future__ import annotations

import re

_CONTROL = re.compile(r"[\x00-\x08\x0b\x0c\x0e-\x1f\x7f\u200b-\u200d\ufeff]")


def clean_text(value: object, limit: int = 500) -> str:
    if value is None:
        return ""
    text = " ".join(_CONTROL.sub("", str(value)).split())
    if len(text) <= limit:
        return text
    return text[: limit - 1].rstrip() + "…"

"""YAML frontmatter iz SKILL.md fajlova."""
from __future__ import annotations

import yaml


class FrontmatterError(Exception):
    """Frontmatter ne postoji ili nije ispravan. Poruka nikad ne sadrži tekst fajla."""


def parse_frontmatter(text: str) -> dict:
    lines = text.lstrip("\ufeff").splitlines()
    if not lines or lines[0].strip() != "---":
        raise FrontmatterError("nema frontmatter")
    for index in range(1, len(lines)):
        if lines[index].strip() in ("---", "..."):
            block = "\n".join(lines[1:index])
            break
    else:
        raise FrontmatterError("frontmatter nije zatvoren")
    try:
        data = yaml.safe_load(block)
    except yaml.YAMLError:
        raise FrontmatterError("neispravan YAML") from None
    if not isinstance(data, dict):
        raise FrontmatterError("frontmatter nije mapa")
    return data
```

"""Čitanje fajlova sa limitima, linkovi i pretraga SKILL.md fajlova."""
from __future__ import annotations

import os
from collections.abc import Callable
from dataclasses import dataclass

from atlas.identity import norm_path

MAX_TEXT_BYTES = 1024 * 1024
CONFIG_MAX_BYTES = 32 * 1024 * 1024


class FileTooLarge(Exception):
    """Fajl je veći od dozvoljenog limita."""


def read_text_limited(path: str, limit: int = MAX_TEXT_BYTES) -> str:
    if os.path.getsize(path) > limit:
        raise FileTooLarge(path)
    with open(path, "rb") as handle:
        data = handle.read(limit + 1)
    if len(data) > limit:
        raise FileTooLarge(path)
    return data.decode("utf-8-sig", errors="replace")


def is_within(child: str, parent: str) -> bool:
    c, p = norm_path(child), norm_path(parent)
    try:
        return os.path.commonpath([c, p]) == p
    except ValueError:
        return False


def link_info(path: str) -> tuple[bool, str | None]:
    """(True, krajnji cilj) ako putanja ili neki njen predak prolazi kroz link."""
    logical = os.path.normcase(os.path.normpath(os.path.abspath(path)))
    if norm_path(path) == logical:
        return False, None
    return True, os.path.realpath(path)


@dataclass
class FsOps:
    listdir: Callable[[str], list[str]] = os.listdir
    isdir: Callable[[str], bool] = os.path.isdir
    isfile: Callable[[str], bool] = os.path.isfile
    realpath: Callable[[str], str] = norm_path
    lexists: Callable[[str], bool] = os.path.lexists


REAL_FS = FsOps()


def find_skill_files(
    root: str,
    exclude: frozenset[str],
    max_depth: int = 4,
    ops: FsOps = REAL_FS,
) -> tuple[list[str], list[tuple[str, str]]]:
    """Logičke putanje SKILL.md fajlova kroz dati root i lista (kod, putanja) problema."""
    found: list[str] = []
    problems: list[tuple[str, str]] = []

    def walk(directory: str, depth: int, stack: frozenset[str]) -> None:
        real = ops.realpath(directory)
        if real in stack:
            problems.append(("link-cycle", directory))
            return
        stack = stack | {real}
        skill = os.path.join(directory, "SKILL.md")
        if ops.isfile(skill):
            found.append(skill)
            return
        if depth >= max_depth:
            return
        try:
            names = sorted(ops.listdir(directory))
        except OSError:
            problems.append(("unreadable-dir", directory))
            return
        for name in names:
            if name in exclude:
                continue
            child = os.path.join(directory, name)
            if ops.isdir(child):
                walk(child, depth + 1, stack)
            elif ops.lexists(child) and not ops.isfile(child):
                problems.append(("broken-link", child))

    walk(root, 0, frozenset())
    return found, problems
```

"""MCP serveri iz Claude JSON, .mcp.json i Codex TOML konfiguracija. Bez tajni."""
from __future__ import annotations

import os
import re

from atlas.config import Config
from atlas.fsutil import link_info
from atlas.identity import make_id, norm_path
from atlas.model import Item, Location
from atlas.scan.collector import Collector
from atlas.scan.common import load_json_source, load_toml_source
from atlas.textutil import clean_text

TRANSPORTS = {"stdio": "stdio", "http": "http", "sse": "sse",
              "streamable-http": "http", "streamable_http": "http"}
EXEC_RE = re.compile(r"^[A-Za-z0-9._-]{1,64}$")
ENV_RE = re.compile(r"^[A-Za-z_][A-Za-z0-9_]{0,63}$")


def describe_server(entry: dict) -> dict[str, str | list[str]]:
    """Samo dozvoljena polja. args, env vrijednosti, url i headers se nikad ne čitaju u izlaz."""
    declared = entry.get("type") or entry.get("transport")
    if isinstance(declared, str) and declared.lower() in TRANSPORTS:
        transport = TRANSPORTS[declared.lower()]
    elif isinstance(entry.get("command"), str):
        transport = "stdio"
    elif isinstance(entry.get("url"), str):
        transport = "http"
    else:
        transport = "unknown"
    meta: dict[str, str | list[str]] = {"transport": transport}
    command = entry.get("command")
    if isinstance(command, str) and command.strip():
        base = re.split(r"[\\/]", command.strip())[-1]
        meta["executableName"] = base if EXEC_RE.fullmatch(base) else "unknown"
    names: set[str] = set()
    env = entry.get("env")
    if isinstance(env, dict):
        names.update(k for k in env if isinstance(k, str))
    env_vars = entry.get("env_vars")
    if isinstance(env_vars, list):
        names.update(v for v in env_vars if isinstance(v, str))
    env_names = sorted(n for n in names if ENV_RE.fullmatch(n))
    if env_names:
        meta["envNames"] = env_names
    return meta


def add_servers(
    collector: Collector,
    servers: object,
    *,
    source_path: str,
    profile: str | None,
    scope: str,
    project_path: str,
    fmt: str,
    project_index: dict[str, str],
) -> None:
    if not isinstance(servers, dict):
        collector.warn("warn", "bad-format", source_path, "mcpServers nije objekat")
        return
    source_norm = norm_path(source_path)
    project_norm = norm_path(project_path) if project_path else ""
    via_link, target = link_info(source_path)
    for name in sorted(servers):
        entry = servers[name]
        if not isinstance(entry, dict):
            collector.warn("warn", "bad-format", source_path, "MCP stavka nije objekat")
            continue
        meta = describe_server(entry)
        meta["scope"] = scope
        meta["sourceFormat"] = fmt
        if project_path:
            meta["projectPath"] = project_path
        item = Item(
            id=make_id("mcp", profile or "", source_norm, scope, project_norm, name),
            kind="mcp",
            name=clean_text(name, 100) or "(bez imena)",
            locations=[Location(path=source_path, profile=profile, via_link=via_link,
                                link_target=target, root_label=fmt)],
            metadata=meta,
        )
        collector.add_item(item)
        project_id = project_index.get(project_norm) if project_norm else None
        if project_id:
            collector.relate(item.id, project_id, "configured-for")


def scan_mcp(
    config: Config,
    collector: Collector,
    project_mcp_files: list[tuple[str, str]],
    project_index: dict[str, str],
) -> None:
    for src in config.mcp_sources:
        common = {"source_path": src.path, "profile": src.profile, "fmt": src.format,
                  "project_index": project_index}
        if src.format == "codex-toml":
            data = load_toml_source(collector, "mcp", src.path)
            if data is not None and "mcp_servers" in data:
                add_servers(collector, data["mcp_servers"], scope="user", project_path="", **common)
            continue
        data = load_json_source(collector, "mcp", src.path)
        if data is None:
            continue
        if not isinstance(data, dict):
            collector.warn("warn", "bad-format", src.path, "očekivan JSON objekat")
            continue
        if "mcpServers" in data:
            if src.format == "mcp-json":
                add_servers(collector, data["mcpServers"], scope="project",
                            project_path=os.path.dirname(src.path), **common)
            else:
                add_servers(collector, data["mcpServers"], scope="user", project_path="", **common)
        projects = data.get("projects") if src.format == "claude-json" else None
        if isinstance(projects, dict):
            for project_path in sorted(projects):
                pdata = projects[project_path]
                if isinstance(pdata, dict) and pdata.get("mcpServers"):
                    add_servers(collector, pdata["mcpServers"], scope="project",
                                project_path=project_path, **common)
    for project_dir, path in project_mcp_files:
        data = load_json_source(collector, "mcp", path)
        if isinstance(data, dict) and "mcpServers" in data:
            add_servers(collector, data["mcpServers"], source_path=path, profile=None, scope="project",
                        project_path=project_dir, fmt="mcp-json", project_index=project_index)

"""Dokumenti kao reference: putanja i naslov, bez sadržaja."""
from __future__ import annotations

import os

from atlas.config import Config
from atlas.fsutil import FileTooLarge, link_info, read_text_limited
from atlas.identity import make_id, norm_path
from atlas.model import Item, Location
from atlas.scan.collector import Collector
from atlas.textutil import clean_text


def document_title(path: str) -> str | None:
    try:
        text = read_text_limited(path)
    except (FileTooLarge, OSError):
        return None
    for line in text.splitlines()[:50]:
        if line.startswith("# "):
            return clean_text(line[2:], 150) or None
    return None


def add_document(collector: Collector, path: str, title: str | None, status: str) -> str:
    doc_id = make_id("document", norm_path(path))
    via_link, target = link_info(path)
    collector.add_item(Item(
        id=doc_id,
        kind="document",
        name=title or document_title(path) or os.path.basename(path),
        locations=[Location(path=path, via_link=via_link, link_target=target)],
        metadata={"referenceStatus": status},
    ))
    return doc_id


def scan_documents(config: Config, collector: Collector) -> None:
    for doc in config.documents:
        if not os.path.isfile(doc.path):
            collector.source("document", doc.path, "missing")
            collector.warn("warn", "source-missing", doc.path, "dokument ne postoji")
            continue
        collector.source("document", doc.path, "read")
        add_document(collector, doc.path, clean_text(doc.title, 150), "listed")

```python
"""Projekti u radnom folderu, prepoznati po manifest markerima."""
from __future__ import annotations

import json
import os
import tomllib
from dataclasses import dataclass, field

from atlas.config import Config
from atlas.fsutil import FileTooLarge, link_info, read_text_limited
from atlas.identity import make_id, norm_path
from atlas.model import Item, Location
from atlas.scan.collector import Collector
from atlas.scan.documents import add_document
from atlas.textutil import clean_text

MARKERS = (("package.json", "node"), ("pyproject.toml", "python"), ("Cargo.toml", "rust"), ("go.mod", "go"))
DOTNET_SUFFIXES = (".sln", ".csproj")
PROJECT_DOCS = ("README.md", "AGENTS.md", "CLAUDE.md")


@dataclass
class ProjectScan:
    index: dict[str, str] = field(default_factory=dict)
    mcp_files: list[tuple[str, str]] = field(default_factory=list)


def find_markers(folder: str) -> list[str]:
    found = [name for name, _ in MARKERS if os.path.isfile(os.path.join(folder, name))]
    try:
        names = sorted(os.listdir(folder))
    except OSError:
        names = []
    found += [n for n in names if n.lower().endswith(DOTNET_SUFFIXES) and os.path.isfile(os.path.join(folder, n))]
    return found


def project_type(markers: list[str]) -> str:
    for name, kind in MARKERS:
        if name in markers:
            return kind
    if any(m.lower().endswith(DOTNET_SUFFIXES) for m in markers):
        return "dotnet"
    return "other"


def _load_manifest(collector: Collector, path: str, parser) -> object | None:
    try:
        return parser(read_text_limited(path))
    except FileTooLarge:
        collector.warn("warn", "file-too-large", path, "manifest je veći od 1 MiB")
    except (OSError, ValueError):
        collector.warn("warn", "bad-manifest", path, "manifest nije ispravan")
    return None


def _manifest_info(collector: Collector, folder: str, markers: list[str]) -> tuple[str | None, str, list[str]]:
    name: str | None = None
    description = ""
    scripts: set[str] = set()
    if "package.json" in markers:
        data = _load_manifest(collector, os.path.join(folder, "package.json"), json.loads)
        if isinstance(data, dict):
            if isinstance(data.get("name"), str):
                name = clean_text(data["name"], 100) or None
            if isinstance(data.get("description"), str):
                description = clean_text(data["description"], 500)
            if isinstance(data.get("scripts"), dict):
                scripts.update(clean_text(k, 64) for k in data["scripts"] if isinstance(k, str))
    if "pyproject.toml" in markers:
        data = _load_manifest(collector, os.path.join(folder, "pyproject.toml"), tomllib.loads)
        project = data.get("project") if isinstance(data, dict) else None
        if isinstance(project, dict):
            if name is None and isinstance(project.get("name"), str):
                name = clean_text(project["name"], 100) or None
            if not description and isinstance(project.get("description"), str):
                description = clean_text(project["description"], 500)
            if isinstance(project.get("scripts"), dict):
                scripts.update(clean_text(k, 64) for k in project["scripts"] if isinstance(k, str))
    return name, description, sorted(s for s in scripts if s)


def _add_project(collector: Collector, result: ProjectScan, folder: str) -> None:
    markers = find_markers(folder)
    name, description, scripts = _manifest_info(collector, folder, markers)
    metadata: dict[str, str | list[str]] = {"projectType": project_type(markers)}
    if markers:
        metadata["markers"] = markers
    if scripts:
        metadata["scriptNames"] = scripts
    project_id = make_id("project", norm_path(folder))
    via_link, target = link_info(folder)
    if not collector.add_item(Item(
        id=project_id, kind="project", name=name or os.path.basename(folder), description=description,
        locations=[Location(path=folder, via_link=via_link, link_target=target)], metadata=metadata,
    )):
        return
    result.index[norm_path(folder)] = project_id
    for doc_name in PROJECT_DOCS:
        doc_path = os.path.join(folder, doc_name)
        if os.path.isfile(doc_path):
            collector.relate(project_id, add_document(collector, doc_path, None, "project-doc"), "documented-by")
    mcp_path = os.path.join(folder, ".mcp.json")
    if os.path.isfile(mcp_path):
        result.mcp_files.append((folder, mcp_path))


def scan_projects(config: Config, collector: Collector) -> ProjectScan:
    result = ProjectScan()
    candidates: list[str] = []
    for root in config.project_roots:
        if not os.path.isdir(root):
            collector.source("project-root", root, "missing")
            collector.warn("warn", "source-missing", root, "folder sa projektima ne postoji")
            continue
        try:
            names = sorted(os.listdir(root))
        except OSError as exc:
            collector.source("project-root", root, "error")
            collector.warn("warn", "unreadable-dir", root, f"folder nije čitljiv ({type(exc).__name__})")
            continue
        collector.source("project-root", root, "read")
        for name in names:
            if name in config.exclude_names or name.startswith("."):
                continue
            folder = os.path.join(root, name)
            if os.path.isdir(folder) and find_markers(folder):
                candidates.append(folder)
    for extra in config.extra_projects:
        if os.path.isdir(extra):
            candidates.append(extra)
        else:
            collector.warn("warn", "source-missing", extra, "projekat iz extraProjects ne postoji")
    seen: set[str] = set()
    for folder in candidates:
        key = norm_path(folder)
        if key not in seen:
            seen.add(key)
            _add_project(collector, result, folder)
    return result
```

def ok(_text):

class PublishTests(TempDirTestCase):
    def setUp(self):
        super().setUp()
        self.paths = AppPaths(self.tmp / "app")
        self.a = self.paths.inventory
        self.b = self.paths.report
        self.c = self.paths.catalog

    def leftovers(self):
        found = []
        for folder in (self.paths.data_dir, self.paths.output_dir):
            if folder.exists():
                found += [p.name for p in folder.iterdir() if p.name.endswith((".staged", ".bak"))]
        if self.paths.journal.exists():
            found.append(self.paths.journal.name)
        return found

    def old_set(self):
        for path, text in ((self.a, "A-old"), (self.b, "B-old"), (self.c, "C-old")):
            write(path, text)

    def contents(self):
        return [p.read_text(encoding="utf-8") if p.exists() else None for p in (self.a, self.b, self.c)]

    def test_publish_writes_all_and_cleans_up(self):
        publish(self.paths, [Target(self.a, "A", ok), Target(self.c, "C", ok)])
        self.assertEqual(self.a.read_text(encoding="utf-8"), "A")
        self.assertEqual(self.c.read_text(encoding="utf-8"), "C")

        self.old_set()

            raise ValueError("neispravno")

            publish(self.paths, [Target(self.a, "A", ok), Target(self.b, "B", reject)])
        self.assertEqual(self.contents(), ["A-old", "B-old", "C-old"])

        write(self.a, "A-old")
        write(self.b, "B-old")
        calls = {"n": 0}

        def flaky(src, dst):
            calls["n"] += 1
            if calls["n"] == 2:

            os.replace(src, dst)

        with self.assertRaises(OSError):

        self.assertEqual(self.contents(), ["A-old", "B-old", None])
        self.assertEqual(self.leftovers(), [])

        self.old_set()
        calls = {"n": 0}

        def dying(src, dst):
            calls["n"] += 1
            if calls["n"] == 2:
                raise _Crash()
            os.replace(src, dst)

        with mock.patch.object(writeout, "_rollback", side_effect=_Crash()):
            with self.assertRaises(_Crash):
                publish(self.paths, [Target(self.a, "A", ok), Target(self.b, "B", ok), Target(self.c, "C", ok)],

        self.assertEqual(self.contents(), ["A-old", "B-old", "C-old"])

    def test_no_journal_means_no_recovery(self):
        self.assertFalse(recover_if_needed(self.paths))


    def test_committed_cleanup_interruption_keeps_all_new_outputs(self):
        self.old_set()
        entries = []
        for n, path in enumerate((self.a, self.b, self.c)):
            backup = path.with_name(path.name + ".x1.bak")
            if n != 0:
                write(backup, path.read_text(encoding="utf-8"))
            write(path, "NEW")
            entries.append({"target": str(path), "staged": str(path.with_name(path.name + ".x1.staged")),

        write(self.paths.journal, json.dumps({"phase": "committed", "entries": entries}))

    def test_replace_recovery_is_repeatable_after_interruption(self):
        self.old_set()
        entries = []
        for path in (self.a, self.b, self.c):
            backup = write(path.with_name(path.name + ".x1.bak"), path.read_text(encoding="utf-8"))
            write(path, "NEW")
            entries.append({"target": str(path), "staged": str(path.with_name(path.name + ".x1.staged")),

        write(self.paths.journal, json.dumps({"phase": "replace", "entries": entries}))

            rollback(current[:1])
            raise _Crash()

                recover_if_needed(self.paths)
        self.assertTrue(Path(entries[0]["backup"]).exists())
        self.assertTrue(recover_if_needed(self.paths))
        self.assertEqual(self.contents(), ["A-old", "B-old", "C-old"])
        self.assertEqual(self.leftovers(), [])

    def test_second_lock_is_refused(self):
        paths = AppPaths(self.tmp / "app")
        with atlas_lock(paths):
            with self.assertRaises(LockBusy):
                with atlas_lock(paths):
                    pass
        self.assertTrue(paths.lock.exists())

            pass  # isti persistent lock fajl ponovo se zaključava

                with atlas_lock(paths):
                    pass

    def test_existing_file_without_os_lock_is_reusable(self):
        paths = AppPaths(self.tmp / "app")
        write(paths.lock, "0")
        with atlas_lock(paths):
            self.assertTrue(paths.lock.exists())

- [x] **Step 3: Implementiraj writeout**

`src/atlas/writeout.py`:

Implementirati modul prema sljedećem ugovoru, bez TTL brisanja locka:

1. `atlas_lock`: persistent `data/.atlas.lock` fajl ima najmanje jedan byte. Na Windowsu držati otvoren handle i nonblocking `msvcrt.locking` nad byteom 0; na POSIX-u koristiti `fcntl.flock(LOCK_EX | LOCK_NB)`. Konkurentni vlasnik daje `LockBusy`. Lock se oslobađa zatvaranjem handlea; fajl se **ne briše**, pa nema race-a između inode-a/putanja. OS oslobađa lock i kada proces padne. Starost i sadržaj fajla nisu dokaz vlasništva.
2. `publish`: validirati sadržaj, napraviti jedinstvene stage fajlove i atomskim zapisom journala preći u `backup`. Kopirati prethodne canonical fajlove u backupe. Ako priprema padne, canonical ostaje isti.
3. Kada su svi backupi dovršeni, zapisati `replace` prije prve zamjene. Obične greške zamjene vraćaju stari komplet. `_rollback` kopira svaki backup u zaseban restore-temp pa radi `os.replace`; **ne prebacuje/ne troši sam backup**. Ciljeve koji prije nisu postojali uklanja. Nedostajući očekivani backup u replace fazi daje `RecoveryError`; ne nastavljati kao da je oporavak uspio.
4. Nakon svih uspješnih zamjena **prvo** atomskim zapisom potvrditi journal `committed`, pa tek onda brisati stage/backupe. Prekid tokom čišćenja naredni recovery samo dovršava; nikada ne vraća stare izlaze.
5. Nakon uspješnog rollbacka prvo potvrditi `rolled-back`, pa dovršiti čišćenje. Prekid samog rollbacka ostavlja `replace` i netaknute backupe, pa je ponavljanje bezbjedno. Journal brisati posljednji, nakon dovršenog čišćenja. Grešku čišćenja poslije committed faze prijaviti kao odloženo čišćenje, bez tvrdnje da je objava poništena.
6. `recover_if_needed`: `backup` znači očisti pripremu bez promjene canonical fajlova; `replace` znači idempotentan rollback; `committed` i `rolled-back` znače samo čišćenje. Ne hvatati simuliranu `_Crash`/smrt procesa kao običnu recoverable grešku.
7. Prije pristupa fajlovima validirati journal: dozvoljena faza, lista entry-ja, jedinstveni canonical targets isključivo `paths.inventory`, `paths.report`, `paths.catalog`; stage/backup je u istom folderu kao target, sa očekivanim sufiksom. Nevalidan journal vraća `RecoveryError` bez brisanja i bez promjene drugih fajlova. Dodati test za nepoznatu fazu i target van aplikacije.
8. CLI `scan`, `build`, `refresh` i `open` rade recovery pod istim lockom prije čitanja/objave. `open` oslobađa lock prije pokretanja browsera. `init` ne radi recovery jer ne čita izlaze. Ne obećavati zaštitu od nestanka struje bez fsync/durability protokola; obavezni ugovor je oporavak poslije prekida procesa.

Pored prikazanih unit testova, dodati subprocess test: dok jedan proces drži lock, drugi dobija `LockBusy`; poslije terminate/exit vlasnika novi proces dobija lock nad istim fajlom. Koristiti signal spremnosti kroz stdout i ograničene timeoutove, bez fiksnih sleep pretpostavki.

"""SHA-256 izvornih konfiguracionih fajlova iz configa. Ispisuje samo putanje i hashove."""
from __future__ import annotations

import hashlib
import json
import sys
from pathlib import Path

from atlas.config import load_config


def main() -> int:
    config = load_config(Path(sys.argv[1]))
    files = sorted({r.path for r in config.plugin_registries} | {m.path for m in config.mcp_sources})
    result = {
        path: hashlib.sha256(Path(path).read_bytes()).hexdigest() if Path(path).is_file() else None
        for path in files
    }
    print(json.dumps(result, indent=2, ensure_ascii=False))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
